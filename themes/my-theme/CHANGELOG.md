# Изменения

## 4.0.5

- Проведён полный статический аудит CSS по шаблонам, shortcode и JavaScript темы.
- Удалён неиспользуемый файл `90-korbox.css` (407 строк): в теме отсутствовали соответствующие шаблоны, shortcode и JavaScript.
- Удалены неиспользуемые переменные `--radius-sm` и `--radius-lg`.
- Удалён неиспользуемый класс `.sr-only`.
- Удалены мёртвые стили и разметка `story-card-summary`.
- Удалены декларации ленты, которые всегда перекрывались более поздними правилами `.post-content`.
- Удалено повторное мобильное объявление `body { font-size: 16px; }`.
- Количество CSS-файлов уменьшено с 11 до 10, объём исходного CSS — примерно на 24%.

## 4.0.4

- Главная, архив публикаций, рубрики и теги теперь выводят оформленное содержимое записи до `<!--more-->`.
- Убрано принудительное преобразование анонса в простой текст и ограничение в 150 символов.
- Сохраняются изображения, абзацы, списки, цитаты и подзаголовки, размещённые до разделителя.
- Каждая публикация в списке помещена в отдельный белый блок на светло-сером фоне.
- Добавлен отдельный файл `45-feed.css` для оформления полноформатной ленты.
- Значение `summaryLength` увеличено с 34 до 70 слов для записей без ручного разделителя.

## 4.0.3

- Отключён автоматический вывод изображения из `image` внутри статьи: оно используется только в карточках и SEO.
- Уменьшены размеры заголовков и насыщенность шрифтов на главной, в списках и статьях.
- Шапка переведена на надёжную фиксированную схему и скрывается при прокрутке вниз.
- Блок рубрик упрощён: удалены иконки, уменьшена высота карточек, сохранена горизонтальная прокрутка.

## 4.0.0

- Полная переработка исходной темы.
- Удалены гамбургер-меню и поиск из шапки.
- Добавлена скрывающаяся при прокрутке шапка.
- Добавлена глобальная лента публикаций из рубрики `Pin`.
- Добавлена горизонтальная динамическая лента рубрик.
- Сохранена фиксированная нижняя навигация.
- Сохранён и переработан блок обсуждения ВКонтакте.
- CSS разделён на тематические файлы.
- Переработаны SEO-метаданные и `hugo.toml`.

## 1.0.1

- Исправлена совместимость с Hugo 0.151.0: `hugo.Sites` заменён на доступный в этой версии контекст `Page.Sites`.
- Исправлены SEO-ссылка `hreflang="x-default"` и переключатель языков.
## 1.0.2

- Обновлена тема для современного API Hugo 0.158.0 и новее.
- `LanguageCode` заменён на `Locale`.
- `LanguageName` заменён на `Label`.
- `Lang` заменён на `Name`.
- Убраны предупреждения об устаревших языковых параметрах в Hugo 0.164.0.
