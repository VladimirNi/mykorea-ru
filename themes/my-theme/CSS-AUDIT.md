## Изменения 7.0

`85-work.css`: каталог самущилей, адаптивные фильтры, компактные карточки с необязательной прямоугольной миниатюрой, ссылка в шапке/на главной, компоновка общего футера. Изображения без скругления, системные шрифты. Модуль фильтрации загружается только на странице каталога.

# Стили 6.0

Основной фон — #fff. У фотографий нет скруглений; круглое кадрирование используется только для навигации по рубрикам. Области превью резервируются через aspect-ratio.

Карточки размещены в сетке minmax(0,1fr): 1/2/3 колонки по ширине экрана. Заголовки карточек ограничены тремя строками, заголовок статьи показывается полностью. Применены перенос длинных строк и min-width:0, без глобального overflow-x:hidden.

Наведение на круглые рубрики меняет transform, а не геометрию потока. Поддерживаются prefers-reduced-motion, focus-visible и safe-area нижнего меню. Таблицы и код прокручиваются внутри собственного блока. Добавленные статьи используют общие стили и заголовок H2.
