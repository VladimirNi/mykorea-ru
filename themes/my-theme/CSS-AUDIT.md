# CSS версии 5.0

Стили переписаны по существующим тематическим файлам, а не добавлены поверх старых.
`45-feed.css` оставлен как пояснение совместимости: шаблон post-feed-item теперь
использует общую карточку. Глобальный overflow-x:hidden не применяется.
Списки используют minmax(0,1fr), min-width:0 и перенос длинных строк.
Обрезка заголовков — только в карточках и закреплённой ленте; H1 статьи полный.
Таблицы и pre имеют собственную горизонтальную прокрутку.
Размер шрифта интерфейса задаётся в rem; предусмотрены focus-visible,
prefers-reduced-motion, безопасная область нижнего меню и стили печати.
