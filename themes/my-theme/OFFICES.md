# Самущили: редактирование без сторонних сервисов

Каталог — часть темы Hugo. HTML собирается Hugo, фильтры работают в браузере без запросов к серверу и внешних библиотек. CMS, API, база данных и регистрация не нужны. Контакты и необязательные ссылки на карты — обычные ссылки, никакие карты или мессенджеры не встраиваются.

## Файлы

После установки дополнений из `site-root/`:

- `content/work/_index.ru.md`, `_index.en.md`, `_index.ko.md` — заголовок и описание каталога на трёх языках. Можно писать дополнительный Markdown после front matter.
- `data/work/locations.yaml` — города и районы, с устойчивыми ID и названиями на RU/EN/KO.
- `data/offices/` — по одному YAML-файлу на самущиль. Латинское имя файла с дефисами служит ID карточки: `office-name.yaml` → `#office-office-name`.
- `static/images/offices/` — ваши фотографии, если нужны. Создайте папку самостоятельно. Подойдут заранее уменьшенные WebP/JPEG до 800–1000 px по ширине. В YAML укажите `/images/offices/имя.webp`. Изображения из static не пережимаются Hugo автоматически.

Записи находятся вне темы: при следующем обновлении `themes/my-theme/` они сохранятся. Изменения данных становятся публичными после обычной пересборки и публикации Hugo.

## Добавление

1. Дублируйте `data/offices/example.yaml`, например в `data/offices/hanbit.yaml`.
2. Заполните название, местоположение, реальные контакты и варианты работы. Пустые необязательные поля можно удалить.
3. Назначьте `active: true`. `false` скрывает запись на всех языках.
4. Проверьте страницу через `hugo server`.
5. При проверке сведений обновите `updated: "YYYY-MM-DD"`. Это дата проверки человеком, не дата автоматической сборки сайта.

Шаблон намеренно выключен и не содержит выдуманных контактов. В `preview/` могут быть скриншоты с явно помеченными тестовыми карточками; эти записи в поставку не входят.

## Основные поля

| Поле | Содержание |
| --- | --- |
| `active` | `true` для публикации, `false` для скрытия |
| `name` | Название; строка или переводы `ru/en/ko` |
| `city` | ID города из справочника, пока `ansan` |
| `district` | ID района; пустая строка, если район ещё не уточнён |
| `address` | Корейский адрес самущиля |
| `landmark` | Ориентир, можно на трёх языках |
| `phone` | Телефон строкой, со знаком `+` и кодом страны; пробелы допустимы |
| `telegram`, `kakao`, `map_url` | Полные HTTPS-ссылки; пустые поля не создают кнопок |
| `photo` | Путь к фотографии; без фотографии карточка остаётся компактной |
| `languages` | На каких языках можно общаться в офисе |
| `description` | Короткое описание |
| `updated` | Дата фактической проверки данных в кавычках |
| `profiles` | Список вариантов работы с независимыми условиями |

Необязательный текст можно оставить пустым. Поля `name`, `landmark`, `languages`, `description`, а также `title`, `workplace`, `pay_note`, `note` внутри вариантов поддерживают строку или словарь переводов. При отсутствии нужного перевода используется RU, затем KO, затем EN. Это запасной вывод, не автоматический перевод: чтобы контент был полностью трёхъязычным, заполните все три значения.

## Варианты работы и фильтрация

Внутри `profiles` каждый элемент описывает **один совместимый набор условий**. Например, если одна работа только для мужчин с чонобами, а другая для женщин с ильтаном, укажите две записи. Фильтр «мужчины + ильтан» не должен объединять сведения из разных записей.

| Поле варианта | Значения |
| --- | --- |
| `title` | Короткое название работы |
| `age_min`, `age_max` | Числа, границы включаются; `null`, если граница не задана |
| `gender` | `"male"`, `"female"`, `"any"`, `"unknown"` |
| `overtime` | Чонобы / 잔업: `"yes"`, `"no"`, `"unknown"` |
| `special_shifts` | Тыкыны / 특근: те же три значения |
| `daily_pay` | Ильтан / 일당, дневная ставка: те же три значения |
| `workplace` | Место самой работы, отдельно от местоположения офиса |
| `pay_note` | Сумма, единица оплаты и фактический день выплаты |
| `note` | Дополнительные условия |

**Всегда заключайте `yes`, `no`, `unknown` в кавычки.** Это строковые значения, не булевы флаги YAML. Некорректное значение у опубликованной записи остановит сборку и укажет имя файла. Проверяются город, район, значения пола и условий, границы возраста. Отсутствующие условия трактуются как `unknown`.

- «Неважно» не ограничивает выдачу по этому полю.
- «Есть» выбирает `yes`, «Нет» — только `no`. `unknown` не совпадает ни с одним из них.
- Выбор «Мужчины» включает варианты `male` и `any`; «Женщины» — `female` и `any`; «Любой пол» — только явно не ограниченные `any`.
- При заданном возрасте варианты с обеими неизвестными возрастными границами не выдаются. Только `age_min: 20` означает от 20 лет; только `age_max: 55` — до 55 лет включительно. Не используйте одну границу, если противоположная не открыта, а просто ещё не выяснена: в таком случае оставьте обе `null`, а известный фрагмент поясните в `note`.
- Запись без вариантов работы видна без фильтра условий, но не подтверждает ни одно выбранное условие.
- Город и район относятся к **самущилю**. Рабочее место может находиться в другом городе.
- Ильтан не означает автоматически выплату в тот же день. Уточняйте график в `pay_note`.

При подборе карточки показывают только совпавшие варианты, автоматически раскрывая их. Число возле «Варианты работы» также соответствует показанным вариантам. Поиск работает по отображаемому названию, городу, району, адресу, телефону и языкам общения.

## Районы и новые города

В `data/work/locations.yaml` дан стартовый, неполный список районов для навигации. Дополняйте его нужными кварталами/районами; это не административный классификатор. Используйте уникальные устойчивые ID. Для совпадающих названий районов в разных городах включайте город в ID, например `siheung-jeongwang-dong`.

Чтобы добавить город, скопируйте элемент списка `cities`, задайте новый `id`, переводы `name` и его `districts`. Шаблон и JavaScript менять не нужно. При выборе города список районов автоматически ограничивается им; прежний несовместимый выбор сбрасывается. Если каталог выходит за пределы Ансана, поправьте также заголовки и описания трёх `_index` и ключ `work_eyebrow` в i18n.

## Ссылки, навигация и доступность

Выбранные фильтры отражаются в URL (`?city=ansan&gender=female&daily_pay=yes`). Можно копировать адрес из браузера и отправлять его. Обновление страницы восстанавливает выбор. Каждый ввод не создаёт дополнительный шаг в истории: верхняя «Назад» возвращает на действительно предыдущую страницу, в том числе на другой сайт.

Нажатие названия самущиля добавляет якорь его карточки. Для ссылки на отдельную карточку без ограничений сначала сбросьте фильтры, затем нажмите её название.

Без JavaScript все карточки, контакты и раскрывающиеся варианты доступны; блок фильтров скрыт с пояснением. На телефоне фильтры изначально свёрнуты, на широком экране раскрыты. Поля имеют подписи, результат объявляется через `aria-live`, встроенные шрифты браузера не требуют загрузки.
