# My Korea Media — Hugo-тема

Готовая мобильная медиа-тема для MyKorea.ru.

## Реализовано

- фиксированное нижнее меню: главная, рубрики, поиск, публикации;
- шапка только с логотипом слева и переключателем языков справа;
- фиксированная шапка надёжно скрывается при прокрутке вниз и возвращается при прокрутке вверх;
- под шапкой на всех страницах выводятся 10 последних публикаций из рубрики `Pin`;
- лента `Pin` поддерживает свайп, прокрутку мышью и стрелки;
- заголовки в ленте `Pin` ограничены по длине и двумя строками;
- рубрики на главной автоматически берутся из таксономии Hugo;
- рубрики оформлены компактными карточками без иконок, идут одной горизонтальной строкой и прокручиваются стрелками;
- системная рубрика `Pin` скрыта из блока обычных рубрик;
- сохранён блок перехода к обсуждению ВКонтакте;
- CSS разбит по тематическим файлам;
- добавлены canonical, hreflang, Open Graph, Twitter Card, JSON-LD, RSS и корректный robots.txt;
- сохранены shortcode VK, YouTube, стили KorBOX и блока контактов.

## Установка

Скопируйте папку `my-theme` в:

```text
themes/my-theme
```

Замените основной `hugo.toml` файлом из комплекта и запустите:

```bash
hugo server
```

## Лента публикаций и `<!--more-->`

На главной странице, в разделе «Публикации», рубриках и тегах тема выводит не короткую карточку, а **оформленное содержимое публикации до ручного разделителя**:

```markdown
Первый абзац, изображение и другие элементы, которые должны быть видны в ленте.

<!--more-->

Продолжение статьи, которое открывается на отдельной странице.
```

Разделитель должен находиться **на отдельной строке**. В ленте сохраняется Markdown-оформление: абзацы, изображения, списки, цитаты и подзаголовки. Сам разделитель на сайте не отображается.

Если `<!--more-->` не указан, Hugo создаст автоматическое краткое содержание на основе параметра `summaryLength` в `hugo.toml`.

Публикации в ленте размещены на светло-сером фоне в отдельных белых блоках с рамкой и небольшим отступом, поэтому начало и конец каждого материала хорошо различимы.

## Как закрепить публикацию в верхней ленте

Добавьте публикации рубрику `Pin`. Можно одновременно указать и обычную рубрику:

```yaml
categories: ["Pin", "Новости"]
```

На сайте выводятся 10 последних публикаций с этой рубрикой. Значения меняются в `hugo.toml`:

```toml
[params]
  pinCategory = "Pin"
  pinLimit = 10
  pinTitleLength = 62
```

## Рекомендуемый front matter

```yaml
---
title: "Заголовок публикации"
date: 2026-07-28T12:00:00+09:00
lastmod: 2026-07-28T12:00:00+09:00
description: "Короткое и уникальное описание публикации для лида и SEO."
categories: ["Новости"]
tags: ["Южная Корея", "Жизнь в Корее"]
image: "images/example.webp"
author: "Владимир"
vk_discussion: "https://vk.com/..."
---
```

Параметр `image` используется для карточек публикации, Open Graph и SEO. Тема не выводит его автоматически внутри статьи. Чтобы изображение присутствовало в тексте, добавьте его в Markdown в нужном месте.

Чтобы исключить материал из главной ленты:

```yaml
exclude_from_home: true
```

## Изображения

Тема ищет изображения:

1. в Page Bundle;
2. в `assets/`;
3. по обычному пути из `static/`;
4. по внешнему URL.

Для обработки и создания WebP изображение должно находиться в Page Bundle или `assets/`.

## Важные файлы CSS

- `00-tokens.css` — цвета, размеры, переменные;
- `10-base.css` — основа и типографика;
- `20-header.css` — шапка и языки;
- `30-pin-strip.css` — верхняя лента `Pin`;
- `40-cards.css` — компактные карточки, архивы и рубрики;
- `45-feed.css` — полноформатная лента публикаций и разделение материалов;
- `50-article.css` — статья и блок ВК;
- `60-components.css` — поиск, пагинация, футер;
- `70-bottom-nav.css` — нижнее меню;
- `80-responsive.css` — адаптивность;
- `90-korbox.css` — калькулятор KorBOX и контакты.
