# My Korea Media — 5.0

Переработанная Hugo-тема: спокойный светлый фон, компактные карточки с миниатюрами слева, аккуратная типографика и нижняя навигация с логотипом по центру.

## Установка

1. Сохраните копию прежней папки `themes/my-theme`.
2. Замените её целиком папкой `my-theme` из этого архива. Не накладывайте новые шаблоны поверх старых: в версии 5.0 используются имена шаблонов новой системы Hugo.
3. Сохраните свой действующий `hugo.toml`, материалы, изображения и языковые настройки. Менять основной конфиг целиком не нужно.
4. Требуется Hugo **0.158.0 или новее**. Выполните `hugo version`, затем `hugo server` для проверки и `hugo --gc --minify` для сборки.
5. Если проект содержит собственные файлы в `layouts/` или `assets/css/` с теми же именами, они имеют приоритет над темой. Проверьте их, если изменения не появились. После публикации обновите CDN-кэш, если он используется.

## Что изменено

- Главная, архив публикаций, страницы рубрик и отдельных тегов используют один компактный формат: изображение слева, заголовок справа, рубрика и дата.
- Заголовок карточки ограничен тремя строками на всех экранах. Длинные слова и URL переносятся внутри карточки. Полный текст остаётся в ссылке и показывается целиком на странице статьи.
- Изображения имеют постоянную область: 4:3 на компьютере, квадрат на телефоне. Кадрирование через `object-fit: cover` не деформирует картинку.
- Вместо длинных HTML-анонсов выводятся только данные карточки. `<!--more-->` больше не влияет на визуальную длину ленты; в самом материале разделитель работает как раньше, RSS использует настройки Hugo.
- Рубрики на главной — компактная прокручиваемая строка. Каталог рубрик — сетка, каталог тегов — алфавитный указатель со счётчиками.
- Закреплённые материалы из рубрики `Pin` — горизонтальная лента только на главной. Системная рубрика скрыта в обычных списках и метках статей.
- Верх страницы свободен от фиксированного меню. Нижняя панель: рубрики, публикации, логотип со ссылкой на главную, поиск, выбор языка. На одноязычном сайте вместо языка показываются теги.
- Переключатель языка открывается без JavaScript. Если перевод материала существует, ссылка ведёт на него; иначе — на главную выбранного языка. Escape и клик снаружи закрывают меню при включённом JavaScript.
- В статье: удобная ширина чтения, полный заголовок, лид, автор, дата, теги, похожие статьи, оформленные цитаты и локальная прокрутка широких таблиц/кода.
- Сохранены SEO-метаданные, RSS, robots.txt, VK-обсуждения, shortcode `vk`, `youtube`, `toc`, RU/EN/KO.
- Нет сторонних шрифтов, UI-библиотек и новых внешних скриптов. Поиск Google CSE и авторские вставки VK/YouTube по-прежнему используют внешние сервисы.

## Изображения

Порядок выбора миниатюры: `image` → `thumbnail` → ресурс bundle с именем `cover*`, `featured*` или `thumbnail*` → первое изображение в bundle → первый обычный Markdown image или HTML `<img src>` в исходном тексте. Если картинки нет, выводится нейтральная иллюстрация. Для сложного Markdown, reference-style изображений или shortcode укажите `image` явно.

Для JPEG/PNG/WebP/TIFF/BMP из Page Bundle или `assets/` тема создаёт варианты WebP 192×144 и 384×288 с `srcset`/`sizes`. Внешние URL и файлы `static/` не перекодируются: они визуально уменьшены, но размер загрузки остаётся исходным. Для таких источников лучше заранее готовить миниатюры или использовать bundle.

SVG, GIF, AVIF и другие неподдерживаемые обработчиком форматы выводятся без принудительной конвертации. Изображение из `image` **не дублируется автоматически в статье**: используйте Markdown в нужном месте, как в прежней версии.

## Необязательные параметры

Добавьте нужные строки в уже существующую секцию `[params]`, не создавая её повторно:

```toml
[params]
  # Путь к вашему логотипу в static/ или внешний URL.
  logo = "images/logo.webp"
  shortTitle = "Моя Корея" # используется при отсутствии logo
  homeHeading = "Моя Корея" # иначе site.Title
  homeEyebrow = "Жизнь в Корее"
  homePageSize = 12
  archivePageSize = 12
  showPinStrip = true
  pinCategory = "Pin"
  pinLimit = 6
  hiddenCategories = ["Pin"]
  showArticleToc = false # включить сворачиваемое содержание
  # Ограничить главную и рекомендации разделом публикаций:
  mainSections = ["posts"]
```

Не указывайте путь к отсутствующему логотипу. Если `logo` не задан, тема использует существующий `static/images/logo.webp`, а при его отсутствии — название сайта. Размер и пропорции существующего логотипа сохраняются.

`pinTitleLength` больше не используется: вместо обрезки исходного текста применено ограничение по строкам. `showArticleToc` по умолчанию выключен. При наличии shortcode `toc` дополнительное содержание не создаётся.

## Поиск и разделы

Нижнее меню предполагает адреса `/posts/`, `/categories/`, `/tags/`, `/search/` с языковыми префиксами Hugo. Сохранены адреса исходной темы. Если у вас другая структура, измените ссылки в `layouts/partials/bottom-nav.html` и `layouts/home.html`.

Для страницы поиска нужен `content/search.md` с `layout: search` и существующий параметр `params.search.googleCSEID`. Без идентификатора показывается сообщение, что поиск не настроен. Тема не выдумывает идентификатор CSE и не меняет ваш конфиг. В многоязычном проекте создайте страницы поиска для каждого языка. Пример минимальных файлов — в `exampleSite/` (это подсказка по настройке, не данные для замены вашего сайта).

Таксономии в конфиге:

```toml
[taxonomies]
  category = "categories"
  tag = "tags"
```

## Основные файлы

- `layouts/home.html` — главная.
- `layouts/section.html`, `term.html`, `partials/archive.html` — списки публикаций.
- `layouts/taxonomy.html` — каталоги рубрик и тегов.
- `layouts/single.html` — статья.
- `layouts/partials/post-card.html` — карточка.
- `assets/css/00-tokens.css` — цвета и размеры.
- `assets/css/40-cards.css` — списки и каталоги.
- `assets/css/50-article.css` — оформление статьи.
- `assets/css/70-bottom-nav.css` — нижнее меню.
- `assets/css/80-responsive.css` — мобильные стили и печать.

Проверки описаны в `VALIDATION.md`. Примеры на скриншотах используют демонстрационные тексты и иллюстрации; ваши публикации и фотографии в архив не добавлялись.
